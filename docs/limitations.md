# Известные ограничения «АкроБати»

Что программа сознательно не делает или делает иначе, чем Acrobat. Пополняют сессии очереди (эталон 3.x
«Граничные случаи», план); руководство (9.4) ссылается на этот файл.

## Формы и JavaScript (этап 6)

- **JavaScript выключен по умолчанию** (эталон 7.2): включается для файлов из доверенных папок (Диспетчер
  доверия), по кнопке «Включить для этого файла» и настройкой «Все документы»; в защищённом просмотре — никогда.
  При выключенном формы заполняются, но форматы (AFNumber_Format…), проверки и вычисления не идут.
- **Подмножество Acrobat JavaScript** — то, что даёт MuPDF 1.28.5 (MuJS): `app.alert`, `console.println`,
  `this.getField`, `resetForm`, `calculateNow`, свойства документа и поля, `util.printf` и библиотека AF*
  (`util.js` MuPDF). `app.response`, `this.saveAs`, `submitForm`, `importDataObject` — заглушки: вызов пишется в
  журнал, сценарий получает `null`; `print`, `mailDoc`, `app.execMenuItem` ничего не делают (запись в журнал);
  `app.launchURL` открывает адрес только после подтверждения, как ссылку.
- **Таймаута сценария нет**: прерывать выполняемый сценарий MuJS не умеет. Защита — предел MuPDF в 10 млн
  инструкций и 100 МБ памяти на вызов (бесконечный цикл останавливается ошибкой «script ran too long»);
  сценарий идёт только в потоке документа и интерфейс не блокирует.
- **`app.alert`** — не больше трёх окон подряд на одно действие человека (security-36); остальные получают
  ответ по умолчанию без окна. Окно, на которое не ответили 60 с, считается закрытым («ОК»).
- **XFA** не поддерживается: показывается AcroForm-часть документа и полоса «XFA не поддерживается».
- **Поле пароля** хранит значение в файле (Acrobat его не сохраняет); на странице — звёздочки.
